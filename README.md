## 日常使用

1. 在“配置”中维护人员、航班模板、每周航班计划、岗位和规则，或导入配置模板。模板航班号支持使用 `CX937(早)`、`CX937(晚)` 这样的后缀区分不同时间版本；修改模板航班号会同步岗位规则和规则引用。岗位规则分组内可选择目标航班，一键复制全部岗位及资质人员；目标已有岗位时会先确认覆盖。
2. 在“航班”中确认当天航班、时间、运力和岗位；也可以使用在线查询生成增删建议。在线查询不可用时不影响本地排班。
3. 选择工作日期并生成排班，在真实任务进度完成后查看班表、右侧提前下班与下午无航班名单、人员负荷和规则反馈。
   班表下方的“人员当日航班”默认显示当前日期，可切换查询其他已归档工作日；每名常规人员只显示去重后的航班号，不列岗位，行政支援人员不进入统计。没有完整归档或只有末班重点记录时，页面会明确提示而不会补猜全天航班。
   规则页“同一工作班航班数均衡”会在岗位覆盖、值班、KE166、资质、状态、时间冲突、最小衔接和工时等安全规则锁定后，使参与比较人员承担的不同航班数最大值与最小值相差不超过 1。同一航班多个岗位只计一次；行政支援、病假、休假以及当天没有安全候选航班的人员不参与比较。无法在安全规则下完成均衡时，只保留带结构化均衡回退证据的空岗；后置覆盖、恢复、轮岗和人工调整不会为均衡制造空岗。
   当天需要安排半休时，在生成或重新排班前打开“半休人员”并勾选一个或多个正常常规人员。下午半休人员只能承担 12 点前开始的岗位，上午半休人员只能承担 12 点后开始的岗位；这是硬限制，恢复、轮岗、覆盖和岗位压缩都不能突破。非分队长半休人员必须至少安排一个符合时段的合法岗位，不能全天没有班；分队长是唯一例外。若非分队长没有符合时段的合法岗位，或因冲突、工时等硬约束无法落实至少一班，本次排班不会采用，原班表保持不变，并提示具体原因。系统先遵守值班、资质、冲突、衔接和工时等安全规则，再在允许时段内优化半休人员的岗位；非半休人员即使命中疲劳恢复、截止保护或严格恢复目标，只要缺少其他安全人选，也会继续正常上班填补半休造成的后续空缺。严格恢复只在这类实际补位时让步，普通换人仍不能突破。半休选择只影响当前日期，切换日期后自动清空。
   点击“重新排班”会先打开当前日期的航班确认窗口。窗口显示全部本地航班模板，并补充当天已有但模板中没有的航班；默认只勾选当天已有航班并带入当前预定人数，其他航班人数默认 0。可以临时增减航班、修改人数后再确认，人数达到岗位配置的“启用旅客人数”时对应柜台才会自动安排。取消、点击“停止，不采用”或计算失败时，原航班、人数和班表保持不变；明确点击“停止并采用”时，只有完整安全方案可与本次航班选择一起提交。本次选择不会改写航班模板、每周计划或历史。
4. 按需要拖拽换人、交换岗位、填写临时岗位或调整当日轮值。人工调整可以突破资质、时间重叠、衔接和每日工时限制，但会在单元格、反馈和归档中持续标明原因；病假、休假、夜班能力不足、人员不存在、行政支援模式关闭和机动督导兼任范围仍不能突破。
   规则页可添加多条“同航班人员互斥”，每条规则都能单独启用或停用；停用后保留配置，且当前班表只会标记为需要重新排班，不会被自动改写。航班留空表示任何航班都不能同班，选择具体航班则只限制该航班。启用的规则会参与自动排班、后续校验和人工调整警告。
   班表中的岗位名称或人员格旁的加人图标可以点击查看该岗位当前合格且空闲的常规人员；列表不显示有时间冲突或不合格的人员，点击姓名即可直接安排。人员输入框本身仍保留原有姓名补全列表，用于手工输入。
5. 在“统计”中核对月度值班、CX航前、备勤和岗位承担次数，在“历史”中复核已归档班表。完整历史日期展开后点击“编辑该日排班”，系统按当前航班模板和岗位配置重建该日班表并恢复历史人员；可在排班页继续换人、交换或清空岗位，点击“保存并更新历史”后只覆盖该日期。编辑期间原历史保持不变，点击“取消编辑”放弃草稿并恢复进入编辑前的当前班表；仅末班重点历史记录不能编辑。
6. 导出 Excel、离线 HTML 或 PNG；确认当天结果后可以仅归档，或点击“归档并排后天”，确认目标星期预设的航班后再归档和生成。统计页的末班重点岗位表可切换自然月份，并按“人员 × 已勾选航班”同时显示各航班次数；点击某个航班数字只展开该航班实际配置的类别，申报/送资料二合一岗位只显示“送资料”，同航班另有独立申报岗时仍显示“申报”。当前月份可一键清零，也可用“导出次数 / 导入次数”专用 Excel 在设备间完整迁移最终次数；专用文件只包含各航班实际适用类别，旧文件若给二合一岗位提供“申报”行会整表拒绝并提示重新导出。导入前会预览并校验月份、人员、航班、类别、整数和完整性，确认后覆盖该月文件范围，不重复累加。清零和修正都会进入下一次自动排班均衡，人员列表不会因手工改数重新排序。配置导出仍保留原始“末班重点次数修正”账本。历史页还可以导入旧版按日期分工作表的手工排班 Excel，导入时手动选择工作日期，系统只展示并写入当前末班重点规则范围内且实际晚于末班界线的重点岗位记录；下午航班和其他岗位不计入末班重点次数。此类“只导入末班重点”的记录保留岗位业务备注和配置疲劳点，用于末班重点轮换、恢复保护和已知重点疲劳，但不会被当作完整班表参与“下午无航班”“提前下班”、完整班次滚动工时或完整连续工作日统计。

统计页的普通重点岗位区块也可独立切换自然月份，默认跟随当前工作日；该区块按所选月份显示普通重点次数，现有手工修正按钮写入所选月份，不影响末班重点岗位的月份选择。

统计页的月度轮值明细可单独切换值班与备勤月份，并沿用当前工作日的上一休一奇偶组；每个工作班日期仍可直接调整值班和次日备勤人选，CX 航前视图与全局工作日期保持不变。

月度提前下班统计按原配置节点判断最后一班；当天任一航班计划截载晚于 23:00 时整日不计提前下班，分流提前撤岗不改变航班计划截载。旧历史缺少原航班截载快照时，按已保存的结束时间统计。

先在“配置 → 每周航班计划”中为星期一至星期日分别勾选已有航班模板。“归档并排后天”会根据目标日期所属星期默认勾选对应预设，并提供“恢复星期预设”“全选”“清空”；弹窗里的临时增减和每个航班手动填写的预定人数只影响本次生成，不会改写每周计划。预定人数达到岗位配置的启用旅客人数时，该岗位才会自动安排。取消、停止、失败或没有完整安全方案时，原日期、航班、历史和班表均保持不变。这个流程只使用本机模板，不要求网络或在线查询。

不参加备勤的人员，可以在“配置 → 人员信息”中关闭“备勤资质”。关闭后，自动轮值、手工选择和值班备勤 Excel 导入都不会再把该人员安排为备勤；若合格人员不足，备勤席位会留空并提示。

点击“生成排班”或“归档并排后天”先选航班、填写预定人数，并确认当前组人员的正常、病假、休假状态，再点击确认开始排班。弹窗调整在排班成功前只是草稿；成功后人员状态与配置页同步。取消、失败或任一种停止均保留原航班、人员状态和班表。“重新排班”保持原有航班选择流程。

每次点击“生成排班”或“重新排班”，系统只计算当前选中的日期，不会提前计算未来两三个班。当天需要自动安排的岗位和所有合格人员会放在一起考虑；当前月份没有末班重点岗位人工次数账本时最多计算 150 秒，录入或清零该月次数后最多计算 5 分钟，求出完整结果会立即结束，不会固定等待满 5 分钟。超过允许时间或计算失败时不会采用半成品，原班表会继续保留；确实缺少合格人员的岗位可以留空，并显示原因。计算期间可以点“停止，不采用”立即结束并保留原班表；重新排班和其他即时计算流程中，后台准备好一份完整且通过安全检查的方案后，“停止并采用”会启用，可结束后续公平优化并采用最近的安全方案；本次新增的生成与归档预检流程按上述停止回退约定执行。跨工作日恢复目标可选择“优先避开”或“严格限制”；严格限制通常禁止恢复人员承担目标岗位，只有填补半休造成的后续空缺时才受控让步。没有半休补位例外且无安全完整方案时，本次排班失败并保留原班表。
排班失败时右下角的红色错误提示会一直保留，直到点击提示右侧的关闭按钮；成功和普通提醒仍会按原定时间自动消失。

次班截止时间是上一班末班重点人员在下一班最晚允许继续工作的界线，不要求恰好在该时刻下班。存在多个完整安全方案时，系统按截止更早、上一班结束更晚、最终工作结束更早的顺序，优先把更早下班机会给受保护人员。

人员配置中勾选“分队长”后，该人员仍可正常承担有资质的岗位，但系统不要求他每天必须出现在班表中，也不会为了凑齐“人人有工时”而专门安排岗位。存在安全替代人员时，连续承担 `KE166` 独立督导的分队长可以整班休息；只有分队长是唯一合格人员或更高优先级规则确实需要时才继续安排。

规则页的“分队长补差岗位保护”按岗位分类列出当前全部“航班号 / 岗位名”，可整类批量保护或允许，也可展开修改单个岗位。普通重点岗位默认保护，排班员明确放开后才可进入补差换人链；值班人员当前岗位、`KE166`、人工、行政支援、已补差落地岗位、督导兼任关联格和特殊布局关联格固定保护，不能从该页关闭。设置随浏览器状态和配置 Excel 保存。

所有明确配置为“机动督导”的顶部岗位都会在普通柜台排定后依次尝试独立安排、允许范围内兼任和安全重排。有不占柜台的合格人员时优先独立；缺员兼任必须同航班、两格同人、工时只计一次，两个岗位的疲劳分别累计，并继续遵守规则页的兼任范围。全部方式都无法安排时，顶部保留空缺和普通告警，不拆已经形成的普通岗位方案。

`KE166` 继续保留额外专项：无法安排时使用专属标红与人工复核文案；若同一常规人员在“跨航班重点人员优先”中被选入 `KE166` 行，并且 `KE166` 行排在该人员对应的重叠航班行上方，督导和柜台要优先保留两名不同常规人员；必要时让排在后面的 `CX937` 等航班岗位空缺，行政支援人员不算这名额外真人。确实没有第二名安全常规人员时，仍保留合法兼任兜底。`KE166` 督导组连续轮岗和跨航班专项不推广到其他航班。

引导人员优先复用同一航班行政支援岗位上已经填写的常规人员；没有这类人员时，再按整条岗位顺序从最下面已经上岗的正常常规人员开始复用。判断依据是人员类型，不是岗位分类：行政支援岗位上的常规人员可以且优先成为引导，行政支援人员本人永远不能成为引导。多个引导岗位依次复用不同人员，且不重复计算工时、疲劳或历史。排班表中任何没有人员的岗位都会以红色显示；半休、KE166 和人工越权仍保留各自说明。

开启行政支援模式后，系统先保证常规体系岗位，再把仍满足资质、状态、夜班、时间冲突、衔接和工时上限的常规人员自动排入行政支援岗位；该规则不限定航班号或航班时间，常规人员已有其他不冲突岗位时也会继续安排。所有常规人员都不能合法承担时，岗位才留空供手工拖入行政支援人员。行政支援人员始终不参加自动排班；常规人员承担支援岗位正常计算工时、疲劳和历史，行政支援人员手工承担仍不计算。

规则页的“普通岗位最小衔接间隔”默认是 90 分钟。同一个人做完一个航班后，到下一个航班开始必须至少留够这段时间；刚好 90 分钟可以，89 分钟不可以。唯一跨航班例外是有效分流：来源岗位已设为“分流”、来源航班在 12:00 及以后开始，按原结束时间计算会与下一航班重叠或衔接不足，配置的提前撤岗能够消除冲突，并且不使用分流就会造成岗位缺口时，可以提前撤岗后接续。同等岗位完整度下优先减少分流转派。自动排班、补缺和轮岗仍严格执行人员状态、资质、夜班能力、时间冲突、衔接和每日工时上限；人工调整可以在这些可控限制上直接落位并报警，系统会保留具体原因，不会把人工越权带回自动排班。病休、夜班能力不足、人员不存在、行政支援模式关闭和机动督导兼任范围仍会阻止人工调整。

规则页还可以按顺序添加“跨工作日资质预留”。例如下一工作班某航班的控制岗位至少要留 1 名合格人员，系统会尽量避免今天把所有控制资质人员都排到过晚的岗位，但被保留的人今天仍可做较早、较轻的工作。它不会提前生成下一班，也不会为了预留故意空掉今天本来能填的岗位；两边实在无法兼顾时，今天岗位照常填满，并明确提示下一班还差几名可用人员。

规则页顶部搜索框可以搜索规则名称、说明、参数名称和当前配置内容。例如输入航班号、岗位关键词或 `90`，对应的规则卡会自动展开，无关规则会暂时隐藏；清空搜索后恢复全部规则。

规则页可设置“末班结束界线”，默认是 `23:00`，并勾选哪些航班参加末班重点岗位轮换。系统先守住分类差值，再避开上一工作班已经承担过任意末班重点岗位的人，然后依次比较本月四类合计、最近 8 个归档工作班合计，最后才分别平衡督导、一号、申报和送资料。同一个岗位的名称和备注合起来同时包含“申报”和“送资料”时只按送资料 1 次处理；分开的申报岗和送资料岗仍各算 1 次。旧账本中二合一岗位的申报修正不迁移、不再参与统计或排班。督导和一号的正常差值为 1，申报和送资料允许差值 2；范围内不报警、不强制追平，督导资质人员也可以因承担督导而少做申报和送资料。

督导、一号、申报、控制和送资料都按航班与岗位滚动轮换：所有合格人员轮完当前次数后，才开始下一轮。一般同岗轮换也把申报/送资料二合一岗位统一归为送资料，和末班统计使用同一口径。重点岗位次数优先于恢复、疲劳、普通岗位衔接和上一班轻重；但不会突破资质、人员状态、夜班、时间冲突、每日工时、值班或 `KE166` 锁定、岗位完整性和严格岗位衔接。

`TR121 / H02` 按“一号”计算，自动排班时每名合格人员每个自然月最多承担 2 次；全部合格人员都达到 2 次后，该岗位自动留空。这个上限只限制自动排班，排班员仍可人工拖拽超过 2 次。值班人员若安排到首选晚撤岗位会使一号次数差超过 1，系统会继续尝试下一个晚撤目标。

统计页的“普通重点岗位”按人员汇总：每个人只显示一行，每个“航司 / 规范岗位”占一列，顶部可选择“全部”或具体岗位；“全部”只显示至少具备一项相关资质的人，选择具体岗位后只显示该岗位当前有资质的人。点击次数才展开实际次数、人工修正和加减按钮，不再把所有人员与岗位组合逐行铺开。

统计页提供统一的“末班重点岗位统计”，默认汇总规则页已勾选航班的月度次数。主表固定人员顺序并显示跨航班四类合计，每个已勾选航班各占一列；点击航班数字只展开该航班实际适用类别的最终次数及加减按钮，二合一岗位只显示“送资料”。取消勾选只会让该航班暂时退出后续规则和当前统计，不会删除历史，重新勾选后会立即恢复。

班表生成后，可以在排班工具栏点击“对比上一班”，直接在当前页面上方展开当前排班日期之前最近一个已归档工作日的只读班表。当前班表继续保留在下方；没有更早归档时按钮显示“暂无上一班记录”。对照内容使用现有历史归档数据，不会修改班表或重新计算排班。

岗位旁出现琥珀色提醒时，点击图标即可打开“调整原因分析”。选择想交换的人员后，页面会先模拟两人岗位交换，列出能改善的情况、人工调整后需要留意的取舍和仍然不能调整的原因；可执行的人工越权不再二次确认，提交前仍会按最新班表做双向检查。

排班计算期间可以继续查看页面和缩放班表，也可以使用两种停止操作；再次计算、切换行政支援、修改数据、导入或归档会提示等待当前任务完成，防止两个操作同时改动班表。当前任务无论成功、失败或停止都会释放后台计算资源，之后可以直接重试。

## 页面入口

| 页面 | 用途                                                         |
| ---- | ------------------------------------------------------------ |
| 总览 | 查看当前日期、航班、人员和排班状态                           |
| 配置 | 维护人员、航班模板、每周计划、岗位和通用参数，导入或导出配置 |
| 航班 | 管理当天航班并进行线上计划对账                               |
| 排班 | 生成、复核、人工调整和导出当天班表                           |
| 规则 | 用中文查看、启停和调整允许配置的排班规则                     |
| 统计 | 管理月度轮值并核对人员与岗位统计                             |
| 历史 | 查看、导入、删除和清空已归档排班                             |

班表根据当前航班和岗位自动生成。航班增加到 5、6、7、8 个或更多时会继续扩展，超过可读宽度后仅班表区域横向滚动；当日轮值在桌面端固定显示于班表右侧，窄屏时自动移到班表上方。

业务数据默认保存在当前浏览器本地；“导出配置”Excel 包含当前正在查看组的配置、每周航班计划和跨全部日期的历史排班。换设备后导入该文件并确认预览，即可恢复旧设备的历史统计；过去记录即使不符合新设备上的当前人员资质也会保留并计入对应人员的轮次、工时和疲劳统计。配置和历史 Excel 只在当前设备中解析，应用没有账号或远端数据写入。

配置或班表发生修改后，如果直接关闭浏览器标签页或窗口，浏览器会先提醒可能有未导出的内容。本提醒不会因为关闭动作自动导出文件；选择留下页面后，请手动导出配置。现有浏览器本地数据保存机制保持不变。

详细规则、数据边界、实现说明和验收标准统一以 [spec.md](./spec.md) 为准，README 不重复维护第二套说明。
